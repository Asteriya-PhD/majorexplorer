# 湖北 MVP 数据 Schema

## 当前状态
- **本目录所有 CSV 都是演示样本**,按真实湖北新高考分布规律生成
- **生产前必须替换为官方数据**:
  - 一分一段表: 湖北省教育考试院 http://www.hbea.edu.cn/ 每年 6 月底发布
  - 院校专业组投档表: 湖北省招办 + 各院校招生网

## CSV 文件清单

### 1. 一分一段表
**文件名**: `hubei_rank_{科类}_{年份}.csv`
- 科类: `物理` or `历史`
- 年份: 2023 / 2024 / 2025

**Schema**:
| 列 | 类型 | 说明 |
|---|---|---|
| score | int | 分数 (150-700) |
| rank | int | 累计位次 (1 = 第一名) |
| count | int | 本分数段人数 |

**示例**:
```csv
score,rank,count
700,100,15
699,115,15
...
580,27000,118
...
150,248000,180
```

### 2. 院校专业组投档表
**文件名**: `hubei_admission_{科类}_{年份}.csv`

**Schema**:
| 列 | 类型 | 说明 |
|---|---|---|
| year | int | 年份 |
| subject | str | 物理 / 历史 |
| school_name | str | 院校全称 |
| school_type | str | 985 / 211 / 普通 / 专科 |
| group_id | str | 专业组编号(同校每年编号一致) |
| xuanke_req | str | 选科要求(展示用) |
| xuanke_subjects | str | 选科要求(机读, `\|` 分隔;空=不限) |
| plan_count | int | 招生计划人数 |
| min_score | int | 当年最低投档分 |
| min_rank | int | 当年最低投档位次 |
| tuition_yuan | int | 学费(元/年) |
| city | str | 所在城市 |
| is_special | str | 是 / 否(中外合作/国家专项等) |

## 替换真实数据时的注意事项

1. **保持列名不变** — 算法模块硬编码了列名
2. **group_id 必须跨年一致** — 算法用 (school_name, group_id) 取近 3 年历史位次
3. **xuanke_subjects 格式** — `"物理|化学"` (首选|再选);再选是"或"关系(任一即可)
4. **历史 3 年必须都有该专业组** — 否则算法丢弃(标记为"无历史数据")

## 数据规模参考
- 一分一段表: ~550 行 (150-700 分,每 1 分 1 行)
- 投档表: 物理类 ~380 行,历史类 ~280 行 (70+ 所校 × 4 专业组/年)
