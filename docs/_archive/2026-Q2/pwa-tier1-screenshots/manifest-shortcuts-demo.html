⚙️ manifest.json 配置

在现有的 manifest.json shortcuts 数组里再加 2 个,达到 4 个

{ "name": "Major Explorer", "shortcuts": [ { "name": "目录", "url": "/m/catalog.html" }, { "name": "推荐", "url": "/m/recommendations.html" }, { "name": "搜索", "url": "/m/search.html" }, // 新增 { "name": "心愿单", "url": "/m/wishlist.html" } // 新增 ] }

🎯 实际效果

  • 减少跳转: 用户从桌面长按 → 直达目标页 (1 步 vs 打开首页 + 点击导航的 2 步)
  • 高频路径优先: 目录 (浏览全部) / 推荐 (查志愿) / 搜索 (找具体) / 心愿单 (管理意向) 都是用户最常访问
  • OS 级集成: 桌面图标右键菜单、Android 长按菜单、Windows 跳转列表都生效
  • 图标统一: 每个 shortcut 可指定独立图标 (目前共用 /m/icon-192.png)
  • 无 app 也能用: 即使没添加为 PWA,Chrome 地址栏也会显示 install 按钮 (Tier 1 加的)

📊 各平台支持度

  • Android Chrome 96+: ✅ 完整支持,长按桌面图标弹出
  • Android Edge / Samsung: ✅ 支持
  • Windows Chrome / Edge: ✅ 任务栏右键 → 跳转列表
  • macOS Chrome: ✅ 程序坞右键 → 菜单
  • iOS Safari 16.4+: ⚠️ 部分支持 (按规范实现但不显眼)
  • Firefox Android: ❌ 不支持
