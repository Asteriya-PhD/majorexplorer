## 📦 视频制作 checklist

- [ ] 录屏准备：开发服务器起在本地，主页 + 电气工程页 + majors.html + 推荐页 各 1 段
- [ ] 录屏参数：竖屏 1080×1920，30fps，无鼠标光标（或用箭头代替）
- [ ] 字号：演示段字幕 ≥ 36px，老人看得清
- [ ] BGM：第一段用钢琴底（情感），演示段用轻电子（节奏），收尾回钢琴
- [ ] 配音：本人 / AI 配音都行；普通话，不要播音腔
- [ ] 封面：用 0 段那句话当封面文字

1. **原文章里"工具不是万能的"那段没在口播稿里**——你觉得要不要？加在哪里？

5. **配音**：你本人录还是 AI 合成？
