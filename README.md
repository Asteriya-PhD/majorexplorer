# 湖北高考志愿推荐 MVP

> **状态**:原型 v0.1,基于规则 + 历史位次驱动的 96 志愿生成器。

## 核心思路(为什么这样做)

1. **位次驱动,不是分数驱动** — 580 分今年和去年能上的学校完全不一样,题难度和报考人数都在变。真正稳的标尺是**全省位次**。
2. **等效分换算** — 2025 年的"38000 位次"换算到 2024 年应该是多少分?用一分一段表反查。
3. **三级硬过滤** — 选科(物理/化学/地理) + 体检(色盲/视力/身高) + 招生计划(院校专业组是否在湖北招生)。
4. **冲稳保概率分级** — 不是简单"位次段匹配",而是基于历史位次分布估录取概率:冲(<30%)、稳(30-70%)、保(>70%)。
5. **96 志愿完整生成** — 真正落地要 96 个可填方案,不是示例 8 所。

## 快速开始

```bash
pip install -r requirements.txt
python cli_demo.py --rank 38000 --subject 物理 --xuanke 物化生
uvicorn api.main:app --reload   # 起 API
open frontend/index.html        # 浏览器打开
```

## 数据来源说明

**重要**:本 MVP 用的 `data/*.csv` 是**按湖北高考真实分布规律生成的样本数据**,不是官方真实数据。

**生产化前必须替换为真实数据**:
- 湖北 一分一段表(物理类/历史类): 湖北省教育考试院每年 6 月底发布
- 院校专业组投档表: 湖北省招办 + 各院校招生网
- 招生计划: 每年 5-6 月

CSV schema 见 `data/README.md`(将在第二轮迭代时补充)。
