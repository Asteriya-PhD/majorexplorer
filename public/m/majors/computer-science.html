一

速览

计算机科学与技术的核心是「算法 + 系统 + 软件工程」三栖, 它是工科里唯一打通「底层硬件 (体系结构) → 中间层 (操作系统/数据库) → 上层应用 (Web/AI)」的全栈学科; 在 2022-2024 互联网深度回调后 2025-2026 趋于理性 (AI/芯片/自动驾驶/量化等新赛道缺口扩大), 它仍是工科起薪最高 + 天花板最宽的赛道, 但「35 岁危机」「算法岗 985 硕 + 顶会硬门槛」「996 加班文化」「AI 编程 (Copilot) 对初级岗的替代」「简历筛 985 + 顶实习 + 顶项目三道关」是五大隐藏坑.

二

什么人适合

在决定之前, 先想清楚自己是哪种人.

Y · YES
🌱 适合来读
  • 对编程有发自内心的兴趣, 课余时间愿意写代码/做项目/刷算法题
  • 逻辑思维强, 喜欢解谜/系统性思考/抽象建模, 数学 (尤其线代/概率) 不排斥
  • 能接受持续学习 — 技术栈 3-5 年一轮迭代 (Spring→SpringBoot→云原生→LLM 框架)
  • 抗压能力好, 接受项目 deadline/on-call/996 是大厂常态
  • 有自学能力 + 信息检索能力, 不依赖课堂教所有东西
N · NO
⛔ 慎入
  • 把计算机当「修电脑/装系统」 — 实际 90% 时间在写代码 + 调 bug + 读英文文档
  • 数学/逻辑思维弱, 抽象概念 (递归/动态规划/分布式一致性) 缺乏耐心
  • 追求朝九晚五、工作生活严格分开 — 大厂核心岗加班是常态
  • 把「年薪百万」当入场券 — 头部大厂 30-55 万是 985 + 顶实习 + 顶项目三关之后的结果, 双非本直接就业 12-20 万是常态
  • 排斥持续学习 — 入行后 5-10 年不迭代技术栈 (LLM/Rust/云原生) 容易被淘汰
三

避坑指南

关于这个专业最常见的几个误区, 看完再决定要不要押.

误区 01
毕业 = 自动高薪
真相
CS 是工科起薪最高 (985 本硕 25-50 万) 但**学历分层最严**的赛道, 双非本科直接就业 12-20 万是常态, 想拿到 985 头部 (字节/阿里/腾讯) 算法岗 30-55 万必须 985 硕 + 顶会论文 (ACL/EMNLP/SIGIR) + 大厂顶实习, 三关缺一不可.
误区 02
算法岗是 CS 应届最优解
真相
2022-2024 互联网深度回调后算法岗严重紧缩, 头部大厂 (字节/阿里/腾讯/百度) 算法岗 2024 校招 HC 比 2020 砍 50%+, 985 硕 + 顶会论文是硬门槛; 应届入场算法岗竞争激烈, 反而后端/前端/数据/测开 HC 稳定, 资深后端 5 年 + 60-100 万是常态.
误区 03
35 岁危机不存在
真相
35 岁危机在 CS 行业真实存在 — 大厂 P7 (技术专家) 是分水岭, 升不上去面临「被优化」; 真实路径是「P7 技术专家」或「P8-P9 管理岗」或「跳槽到外企/独角兽/创业公司」, 三选一; 一线大厂核心岗 35+ 占比不到 15%, 35 岁前必须完成技术深度沉淀 + 管理能力 / 行业资源积累.
误区 04
学 CS 不用读研
真相
985 本科直接就业 22-35 万 (一线大厂后端) 是真实的, 但**头部算法岗/AI Lab/量化核心岗** 90% 要求 985 硕 + 顶会论文; 想走 AI/算法/量化方向建议直接 985 硕, 走工程 (后端/前端/数据) 可以本科直接就业; 海外硕 (CMU/MIT/Stanford/UIUC) 校招 70-150 万是另一条路.
误区 05
AI 编程 (Copilot) 不会替代初级程序员
真相
GitHub Copilot + Cursor + Claude Code 在 2024-2026 已经能完成**基础 CRUD + 简单功能模块**的 60-80% 代码量, 初级 CRUD 岗 (1-3 年经验) 受冲击最大; 真正稀缺的是「系统设计 + 复杂问题拆解 + AI 工程化落地」能力, 纯写代码的岗位正在被压缩, 选方向要避开「纯 CRUD」.

学长学姐说

选专业之前, 听听真正读过的人是后悔还是庆幸. (前 3 条)

"本科 985 CS, 大三在字节跳动 Lark 团队实习 3 个月做会议室预订模块 (用 Go 重写了老 Java 单体, QPS 从 2000 涨到 1.2 万), 校招拿到 TikTok 后端 offer. 在组里学到的最有用的不是技术, 是 code review 的严格度 — 主管对一行 nil 判断的覆盖度都追问, 后来我才理解工程代码和玩具代码的差距."— 字节 TikTok 后端校友 · 字节 TikTok 国际化后端 · 4 年
"985 本 + CMU 硕士, 硕士毕设做的是 Raft 共识优化 (导师 David Mazières 组, 论文投 OSDI 2022), 校招进 Google Cloud Spanner 团队. 海外找工作的核心是「顶会论文 + 强内推」, 我导师直接 refer 给 Google 内部 senior staff, 跳过 HR 简历关. 想走海外路线, 硕士一定要选有顶会 output 的组."— Google Cloud Spanner 校友 · Google Cloud 海外大厂 · 3 年
"本科 985 软工, 大三跟本校 CSE 操作系统课题组做 6.828 (MIT 课程 lab), 啃完 xv6 之后拿到华为 2012 鸿蒙内核 offer. 嵌入式/系统/工业软件这条路没有算法岗光鲜, 但内卷度低 + 国产替代风口 + 工作强度可控 (985 准时下班), 适合对底层系统有执念又不想 996 的同学."— 华为鸿蒙内核校友 · 华为鸿蒙 OS 内核 · 3 年

高考选科要求

新高考 3+1+2 模式下, 不同选科组合可报院校比例.

01
首选物理 + 再选不限 (90% 院校可报, 主流组合)
70%
CS 绝大多数方向 (后端/前端/AI/算法/数据/嵌入式) 几乎都要求物理, 物理是计算机底层逻辑 (电路/电子/数字逻辑) 基础. 再选科目不限, 化/生/地/政都可.
02
首选物理 + 化学 (985 强基/集成电路交叉方向)
15%
部分 985 强基计划/教改实验班 (如清华计算机+集成电路交叉) 要求物+化, 对应计算机系统/硬件/嵌入式方向, 数学物理双强为佳.
03
首选物理 + 生物 (脑机/智能医学工程交叉方向)
10%
少数 985 交叉方向 (脑机接口/智能医学工程/认知神经科学) 接受物+生, 是新兴交叉, 适合对生物+CS 复合方向感兴趣的同学.
04
不限选科 (个别专业极少数, 综评/中外合作)
5%
极少数综合评价/中外合作办学 (如中科大/上交大中外合作) 不限选科, 但 99% CS 专业仍要求物理, 主流以物为硬门槛.
