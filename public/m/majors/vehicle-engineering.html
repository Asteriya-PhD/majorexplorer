车辆工程是机械、电子、控制与新能源交叉的工科专业， 课程正被「电动化、智能化」彻底重塑。新能源风口与自主品牌出海把中位薪资推到 30-60 万/年， 但内燃机与三电/智驾剧烈分化， 选错方向会卡死天花板。

本科 4 年学的课

下面按年级排列。打 ★ 的是对找工作有直接影响的硬课.

大一
高等数学 (微积分 + 线性代数 + 概率统计) · 大学物理 (力学 + 电磁学 + 热学) · 工程制图与 CAD (CATIA / SolidWorks / UG) · 理论力学 (静力学 + 运动学 + 动力学) · 材料力学 (拉压弯剪扭 + 应力 + 变形) · 电工学 (电路 + 电机 + 拖动) · 电子技术基础 (模电 + 数电) · C 语言程序设计 + 单片机原理
大一
大二
汽车构造 (发动机 + 底盘 + 车身 + 电气) · 汽车理论 (动力学 + 燃油经济性 + 平顺性 + 稳定性) · 汽车设计 (总布置 + 零部件 + 校核) · 内燃机原理 (工作过程 + 性能 + 增压) · 汽车试验学 (整车 + 发动机 + 底盘试验) · 汽车电子控制 (ECU + CAN 总线 + UDS 诊断) · 有限元分析基础 (ANSYS / ABAQUS) · 机械设计基础 (公差 + 互换性 + 联轴器/轴承)
大二
大三
清华大学 · 智能网联汽车 + 自动驾驶系统集成 (智驾方向) · 同济大学 · 新能源汽车 + 燃料电池 + 整车能量管理 (新能源方向) · 北京理工大学 · 车辆 NVH + 电动车辆底盘技术 (电动底盘) · 湖南大学 · 汽车车身设计与 CAE (车身轻量化方向) · 吉林大学 · 汽车动态仿真 + 混合动力系统 (传统强校综合方向)
大三
大四
专业实习 (8-12 周) · 毕业论文 / 毕业设计 · 学科竞赛 + 创新创业实践 · 案例研习 + 项目实战 · 社会实践 + 志愿服务
