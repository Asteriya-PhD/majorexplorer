微机电系统工程

工学学士·4 年·普通批本科

MEMS 是把机械做到微米级以下的那门手艺 — 从手机陀螺仪到汽车 ESP, 从可穿戴心率传感器到基因测序芯片, 微机电是智能硬件的「灵魂」.

一

这个专业学什么

微机电系统工程 (MEMS) 的核心是「微传感器 + 微执行器 + 微纳制造 + 半导体工艺」四栖, 它跨机械 + 电子 + 材料 + 物理, 强微米尺度力学 + 半导体工艺 + 微纳制造功底是硬门槛; 在「物联网传感器 + 汽车智能化 + 消费电子微型化 + 基因/医疗微流控」风口下需求稳定, 但「产业规模较小 + 教学开设校稀少 (全国 ≤ 30 所) + 升学率 40-50%」是该专业三大现实变量.

三

避坑指南

关于这个专业最常见的几个误区, 看完再决定要不要押.

误区 01
微机电系统工程 = 机械工程
真相
微机电系统工程 (MEMS) 是「微米级器件 + 半导体工艺」交叉特设专业, 偏微传感器 + 微执行器 + 微纳制造; 机械工程偏宏观机械设计 + 力学仿真. 课程结构差异 50-60%, 就业方向差异 60%+, 不要混淆选专业.
误区 02
MEMS 产业规模很大, 工作好找
真相
MEMS 全球市场规模 ≈ 200 亿美元 (2024), 国内约 50 亿美元, 整体规模远小于 IC 设计 / 互联网; 但单价低、应用广 (单部手机含 10+ 颗 MEMS), 头部公司 (博世/意法半导体/楼氏/歌尔/瑞声/敏芯股份) 校招稳定, 应届主流薪资 10-18 万.
误区 03
MEMS 毕业后只能去半导体厂
真相
MEMS 毕业生就业面比想象广: 半导体 (MEMS 工艺 + 集成) + 消费电子 (歌尔/瑞声/楼氏) + 汽车电子 (博世/大陆/法雷奥 ESP/IMU) + 物联网传感器 + 医疗微流控 + 基因测序 + 光通信 MEMS, 覆盖多个万亿级下游应用.
误区 04
MEMS = 半导体工艺
真相
MEMS 包含「设计 + 工艺 + 封装 + 测试 + 应用」完整产业链; 半导体工艺只是其中一环. MEMS 设计 (传感器/执行器结构设计) + MEMS 应用 (系统集成) 岗位更多, 工艺岗 (光刻/刻蚀/薄膜沉积) 集中在头部晶圆厂, 本科主要走应用 + 测试岗.
误区 05
MEMS 行业薪酬高于普通机械
真相
MEMS 应届主流薪资 10-18 万, 显著高于普通机械 (8-12 万) 但低于 IC 设计 (20-40 万) 与计算机 (15-25 万); 5 年+ 资深 MEMS 工程师/系统应用专家年薪 30-60 万, 顶尖可达 80-150 万, 但行业头部公司对硕博偏好明显.

十

学长学姐说

选专业之前, 听听真正读过的人是后悔还是庆幸. (前 3 条)

"在清华精密仪器系读了本科 + MEMS 方向硕士, 现在做 MEMS 压力传感器设计。最大感受是这门专业「跨」在学科, 既要懂微米尺度力学, 又要懂半导体工艺和电路, 一颗 MEMS 芯片的诞生是机械 + 电子 + 材料 + 物理四个学科的融合."—
"我们这届本科毕业的同学大致三条路: 一是去半导体厂做 MEMS 工艺, 二是去消费电子公司做 MEMS 传感器应用, 三是去车规电子公司做 IMU/ESP。本科直接就业的话, 起薪在工科里中等偏上, 但行业规模比 IC 设计小很多."—
"MEMS 最大的好处是「微米尺度的工程美感」。我博士转到了微流控芯片方向 (基因测序 + IVD), 同学里有做压力传感器的、做 IMU 的、做 RF MEMS 的。如果对微纳器件、半导体、消费电子、汽车智能化的融合有兴趣, 这个专业很前沿."—
十一

高考选科要求

新高考 3+1+2 模式下, 不同选科组合可报院校比例.

01
物理 + 化学 + 生物 (传统理科, 90% 院校可报)
62%
物理+化学是微机电系统工程的核心基组, 半导体物理 + 电路原理 + 力学基础课直接对接, 985 MEMS 强校几乎都要求物理+化学.
02
物理 + 化学 (再选不限)
25%
部分工科院校只锁物+化, 微纳制造工艺 + MEMS 器件物理直接对接, 化学是半导体工艺的前置必修.
03
物理 + 生物 + 化学 (同组, 顺序差异)
8%
与首选组合实质相同, 仅再选科目顺序不同, 多数院校系统按基组识别, 实际可报范围一致.
04
不限选科 (少数综合院校)
5%
少数综合大学接受不限选科, 但 985 MEMS 强校普遍要求物理 + 化学, 不限选科可报范围有限.
