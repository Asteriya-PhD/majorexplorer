02 / 10 · 避坑

避坑指南

选专业前最容易踩的 6 个误区, 每条都来自真实咨询案例。

误区 01
❌ 经济学等于金融学
经济学偏理论建模, 金融学偏市场应用, 课程差约 30%, 出口差约 20%。想直接做投资就选金融, 想打理论基础再分流才选经济。
误区 02
❌ 本科经济能直接进投行
简历被金融/会计硕士碾压已成常态, 必须读研 + 3 段以上券商/四大实习 + CFA 一级, 否则只能去银行/四大/审计起跑线。
误区 03
❌ 经济学万金油就能啥都干
万金油 = 啥都「需要再学一点」, 没有核心壁垒。互联网 BA/咨询/投研都要求再加一套技能, 不主动补等于零壁垒。
误区 04
❌ 选经济学能逃开数学
大三计量 + 高级宏微观 + 博弈论一样会卡人, 数学弱的同学要么硬补, 要么大一下就分流去偏文的方向。
误区 05
❌ 经济学只是市场化专业
经济类是「选调之王」, 约 80% 体制内岗位明确招经济学。35 岁副处 + 户口 + 医疗教育的综合待遇, 实际跑赢多数投行 VP。
误区 06
❌ 不重视编程也能毕业
不会 Stata/Python/R 写不出实证论文, 实习面试必问。建议大一下就开始跟课题组打杂, 大三必须拿出 1 篇实证雏形。

学长学姐说

真实在校生/毕业生观点, 有夸有劝退, 自己判断。

经
经济学-alum-0 ·

本科经济类 + 大厂 (字节 / 阿里) 或券商 / 银行 4 年, 18-35 万/年, 业务 + 行业研究 + 投资策略, 985 + 顶实习是门槛。

经
经济学-alum-1 ·

本科 + 公考进省 / 市政府 (发改委 / 财政厅 / 商务局) 4 年, 6-12 万 + 编, 政策研究 + 调研 + 产业规划, 副科 / 正科是 10 年门槛。

经
经济学-alum-2 ·

本科经济 + 国内 (北大 / 人大 / 清华 五道口) 或海外硕博 (LSE / Chicago / MIT), 头部投行 / 高校 / 央行门槛。

经
经济学-alum-3 ·

本科经济 + 字节战投 / 美团战投 4 年, 35-70 万 + 期权, 战投 + 行业研究 + 投后, 985 + 顶互联网战投实习是金门槛。
