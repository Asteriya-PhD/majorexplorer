隐私政策

本项目由个人开发者独立维护, 坚守「最小数据」原则 — 能不收集的, 一概不收集。

最后更新 · 2026 年 6 月 11 日

一、数据收集声明

本项目不收集任何用户个人数据。

本站为纯静态站点, 不提供用户注册、不设置账号体系、不发起任何形式的数据上报。具体而言:

  • 不使用 Cookie (含第一方与第三方 Cookie)
  • 不进行浏览器指纹识别
  • 不集成任何第三方分析脚本 (Google Analytics / 百度统计 / 神策 / Sentry 等)
  • 不记录 IP 地址、UA、Referer 等访问元信息
  • 不提供评论、点赞、收藏等需要身份识别的功能
  • 无后端数据库, 无服务端日志记录

您在浏览任何页面时, 不会留下任何可关联至个人的痕迹。

二、字体 CDN 第三方加载

本站使用 fonts.loli.net (Google Fonts 中国镜像) 加载网页字体。该镜像站本身为非商业免费服务, 加载过程仅向镜像站发起一次 HTTPS GET 请求以获取 CSS 样式表与字体文件。

理论上, 字体 CDN 可能会接收到您的 IP 地址与浏览器 User-Agent。这是 Web 加载第三方资源的标准行为, 本站不会也无法将这些信息用于任何追踪目的。

字体版权

所用字体 (Bodoni Moda / Inter / JetBrains Mono / Bebas Neue) 均遵循 SIL Open Font License 协议, 属开源字体, 可自由用于非商业用途。如您对第三方字体加载有顾虑, 可在浏览器层面屏蔽 fonts.loli.net 域名, 本站会优雅降级为系统默认字体。

三、未成年人保护

本站面向高考考生及家长群体, 包含未成年用户。我们承诺:

  • 不向任何年龄段用户索取个人信息
  • 不展示任何针对未成年人定向推送的广告 (本站本身无广告)
  • 不收集未成年人画像、行为、位置等敏感数据

四、本站不存储任何内容贡献者数据

本站所有专业介绍内容均由站长基于公开资料独立整理或经 AI 辅助生成, 不接受用户投稿, 不开放评论区, 因此不存在「用户生成内容 (UGC)」及对应的内容贡献者信息收集。

五、政策更新

本政策可能随项目演进而修订, 修订后会在本页顶部更新「最后更新」日期。重大变更会通过站内公告告知。

本政策不设追溯效力, 既往版本不保留公开存档。

六、联系方式

如对本政策有任何疑问、意见或投诉, 可通过以下方式联系:

  • 项目仓库 Issue: 见 GitHub 仓库 (页面底部链接)
  • 电子邮件: 见项目 README 顶部

我们承诺在收到反馈后 7 个工作日内回复。
