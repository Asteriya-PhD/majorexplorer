# Major 精品写作规范 (Curation Checklist)

> 每个精品专业 = 1 次性 2-3h 投入, 永久资产. 50 个 = 100-150h = 半个工作月.
> 写砸了 = 1000 流量/月变 10 流量/月. **宁缺勿滥**.

## 必须做到的 7 件事

### 1. ≥ 4 条独特校友 quote (灵魂, 决定"想不想看完")
- **必须真实存在** 的场景: 引自知乎 100+ 赞回答 / 微博 / 小红书 / 校友访谈
- **必须能截图**: 1 句话, 不超过 60 字, 不要"我当年也迷茫..."
- **必须有冲突感**: 不能都是夸, 1 夸 1 劝退 1 中立 1 鸡汤
- 模板: `{"year": 2018, "current": "字节后端架构师", "quote": "CS 的真正功力是 4 年后还能继续学新东西"}`

### 2. ≥ 1 个独特数据可视化 (避免"换色就完事")
| 专业 | 该有的图 |
|---|---|
| CS | GitHub 1000+ star 项目率 / ACM 区域赛牌数 / 数学课挂科率 |
| 金融 | 校招 target school 命中率 / CFA 一级通过率 / 男女比 |
| 临床医学 | **5+3+X 时间轴** (必画! 决定读不读得起的核心决策) |
| 法学 | 司考通过率 / 红圈所 target school / 律所 vs 公务员 5 年收入曲线 |
| 师范 | 实习月薪 / 入编率 / 男女比 / 公费师范生 vs 普通师范对比 |

### 3. 选科要求 100% 准确 (志愿填报的硬约束)
- 2024 新高考 3+1+2 后, 物理/化学 覆盖率因专业暴增
- 来源: **阳光高考 招生专业目录** (官方) > 高校官网招生章程 > 第三方
- 必须给覆盖率: "全国开设此专业的院校中, 选科要求为 [物理+化学] 的占 X%"

### 4. 薪资数据 标截止日期 + 采样源
- 不要写"年薪 30-50 万" 这种垃圾话
- 写: "P50 = 25 万/年 (麦可思 2024 报告, N=8500 应届)"
- 写: "字节跳动 算法岗 校招 (2024 秋招, 30k×16 薪, N=120 offer)"

### 5. 头部公司 ≥ 6 家, 含层级 (S/A/B)
- S = 顶级 (字节/腾讯/华为/麦肯锡)
- A = 知名 (美团/京东/小红书/中金)
- B = 大量招 (各种中型)
- **不要漏掉新兴**: CS 加 DeepSeek/智谱/百川; 金融加 量化私募 (九坤/明汯)

### 6. ≥ 3 个易踩坑 (劝退清单, 让用户自己决定)
- CS: "35 岁危机是真是假" / "数学不好能不能学" / "考研还是就业"
- 金融: "家里没资源能不能进投行" / "CFA 性价比" / "985 财经 vs 211 综合性"
- 临床医学: "5+3+X 是几年" / "规培月薪 5000 能不能撑" / "儿科急诊没人报"
- 法学: "法考 A 证率" / "红圈所 target school" / "考公 vs 律师 5 年后差距"
- 师范: "入编要等几年" / "公费师范生 6 年定向值不值" / "男生学师范的尴尬"

### 7. 1 句话定位 (Hero 区)
- CS: "编程是载体, 数学是底层。CS ≠ 写代码, 是用计算思维建模现实问题"
- 金融: "金融 = 资金的时间价值 + 风险定价, 适合对数字敏感 + 抗压强的人"
- 临床医学: "学制长, 前期低收入, 35 岁后越老越值钱, 适合家里能撑 10 年的人"
- 法学: "法学不是背法条, 是逻辑 + 表达 + 立场; 顶级律所的起薪和中石油一样高"
- 师范: "师范不是当老师, 是研究'怎么学'; 毕业后去向广: 中小学/教培/教育局/出版社"

## 数据源优先级

| 字段 | 一级源 (官方) | 二级源 | 三级源 |
|---|---|---|---|
| 课程 | 高校官网培养方案 | 知乎/学长 | 学职平台 |
| 院校分布 | 教育部 **学科评估第四轮** (2017) | 双一流名单 | 软科 |
| 头部公司 | 校招官方公告 | 知乎/脉脉 | BOSS 直聘 |
| 薪资 | 麦可思 (年度) | 校招 offer 墙 | 行业报告 |
| 选科 | 阳光高考 招生专业目录 | 高校招生章程 | - |
| 校友 quote | 知乎 100+ 赞 / 校友访谈 | 微博/小红书 | 论坛 |

## 反例 (绝对不写)

- ❌ "本专业就业前景广阔, 薪资待遇优厚" (没数据的废话)
- ❌ "适合所有对该专业感兴趣的同学" (你没说啥)
- ❌ "学长学姐都找到了好工作" (幸存者偏差)
- ❌ 校友 quote 全是夸的 (4 条都夸就是 fake)
- ❌ 薪资只给"30-50 万" (P25/P50/P75 都不标)
- ❌ 选科要求没覆盖率数字 (考生看到"物理"也不知道自己够不够)
- ❌ 头部公司没层级 (字节和不知名公司并列就是骗)

## SEO 友好

- `<title>` 包含专业名 + 年份: "计算机科学与技术专业介绍 2026 高考"
- `<meta description>` 1 句话定位 + 关键数据
- `<h1>` = 专业全称
- `<h2>` = 10 个 Tab 标题
- 静态 HTML 文件名 = 专业 slug (`computer-science.html`), URL 路径 `/{slug}.html`

## 跟 recommender 联调

Tab 10 模板:
```html
<div class="cta-block">
  <h3>基于你的位次, 推荐这些校 + 组</h3>
  <input type="number" placeholder="输入你的高考位次 (如 1234)">
  <input type="number" placeholder="输入你的预估分数 (如 620)">
  <button onclick="window.location='/recommend?pool=cs&rank=...'">推荐志愿</button>
</div>
```

后端: `recommend_with_major_filter(rank, score, year, subject, school_pool)` — `school_pool` 来自 `data/curated/{slug}.json` 的 `top_schools` 校名列表.
