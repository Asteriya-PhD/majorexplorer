## 合规红线

1. **不爬登录后内容** — 阳光高考/BOSS/小红书 都需要登录的页面不爬
2. **不爬个人信息** — quote 必须取得原作者同意, 或注明"摘录自知乎 @xxx (链接)"
3. **不爬受版权保护** — 麦可思报告截图不外传, 只引用数字
4. **不写未经证实** — "传言某专业年薪百万" 不写, 没有数据源的不写
5. **时效性** — 所有数据必须标 `(YYYY-MM)` 截止日期, 超过 1 年标"⚠️ 数据可能过时"

## 缓存策略

`data/_cache/majors/{slug}.json`:
- TTL = 7 天 (长尾 search 结果)
- 5 query 并行, 整 dict 缓存
- 命中缓存 → 0 search, 模板渲染 < 100ms
- 缓存 size 上限 = 50MB, LRU 淘汰

## 5-Query Search 模板 (长尾)

```python
QUERIES = [
  f"{{major}} 主要课程 培养方案",          # 课程
  f"{{major}} 就业方向 头部公司 薪资",     # 就业
  f"{{major}} 学科评估 哪些学校开设",     # 院校
  f"{{major}} 选科要求 高考 招生",         # 选科
  f"{{major}} 学长学姐 知乎 体验",         # quote
]
```

并行 search (asyncio + aiohttp), 整批 5-15s 完成.
