速览

电子信息工程是电子、信息、计算机三大领域的交叉学科，覆盖电路设计、信号处理、通信系统和嵌入式开发。就业面极宽——从芯片设计到互联网算法、从嵌入式到智能硬件——但课业压力大、数理门槛高，被誉为工科中的「万金油」但也是最「难啃」的专业之一。

这个专业学什么?

前 2 年打数理和电路基础：高等数学 / 线性代数 / 概率论与数理统计 / 复变函数与积分变换 / 大学物理 / 电磁场与电磁波 / C 语言程序设计 / 电路分析。这阶段课程密度极高，挂科率最高的「四大名挂」——模电、数电、信号与系统、电磁场与波——都在前两年。实验课占比较大（电路实验 / 模电实验 / 数电实验），需要在面包板上搭电路并用示波器调试。 后 2 年深入专业核心与方向分化：模拟电子技术 / 数字电子技术 / 信号与系统 / 数字信号处理 / 通信原理 / 单片机原理与嵌入式系统 / FPGA 设计与应用 / 自动控制原理 / 微机原理与接口技术。大三开始按方向分流：可选择嵌入式系统（单片机/ARM/Linux 驱动）、通信与网络（移动通信/光纤通信）、集成电路（芯片设计/版图）、信号处理（图像/语音/AI）等。大四以毕业设计 + 企业实习收尾，全国大学生电子设计竞赛是大三/大四标配实践。

什么人适合?

适合数学物理基础扎实（模电信号本质是微积分和复变）、动手能力强（焊电路板、调示波器不嫌麻烦）、愿意持续学习新技术的同学。本专业对抽象思维要求高——电磁场看不见摸不着全靠数学描述，信号处理靠傅里叶变换打通时域频域。如果你喜欢做实物（自己焊个蓝牙音箱、做个智能小车）甚于纯写代码，这会很对胃口。不太适合只想「坐办公室写代码」的人——虽然也能转纯软，但付出比 CS 科班更大的努力。

避坑指南

❌ 「电子信息 = 修电脑装系统」 → 这是最常见的误解。电子信息工程是设计芯片、写嵌入式代码、做信号处理的硬核工科，和修电脑完全不沾边。❌ 课程「广而不精」陷阱 — 从电路到编程到通信到 AI 都学一点，但深度不够。大二还不确定方向的话，大四简历容易「啥都会一点啥都不深」。❌ 「模电数电是废课没用」 → 大错。大厂芯片岗面试必问模电基础（运放/反馈/频率响应），嵌入式岗面试常考数电和微机原理。放弃这些课等于自断后路。❌ 专业难度被低估 — 数电模电信号系统场波被称为「四大名挂」，不少 985 高校挂科率 20%-30%。想要高分需要投入大量时间做实验和做题。❌ 「本科毕业就能做芯片设计」 → 高门槛芯片岗（模拟 IC/数字 IC）几乎只要硕士以上。本科能做的主要是嵌入式开发、FAE（现场应用）、测试验证。芯片系统架构岗一般要求硕士/博士。❌ 硬件方向「前期薪资低」 — 对比同届 CS 纯软拿 20 万+ 年薪，硬件岗起步普遍低 30%-40%，但增长曲线更平稳，10 年经验后差距缩小。

08 / 10 · 学长学姐说

学长学姐说

真实在校生/毕业生观点, 有夸有劝退, 自己判断。

华
华为海思 芯片验证工程师 2020 届 · 知乎 @2025

本科把模电数电信号系统吃透太重要了，面试芯片岗必问这些基础。但说句实话，本科那点焊接和实验课和工业级芯片设计差得远，得自己额外学 Verilog 和 UVM 验证方法学。海思加班确实不轻，但技术积累厚，想搞硬件的能来尽量来。

某
某 985 电子硕 → 大疆嵌入式工程师 2019 届 · 校友访谈 @深圳

电信专业最大的坑是课程设置太杂，从天线到编程到控制全都要学，如果没有大二就确定方向，大四简历会很散。我大二选了嵌入式方向往死里学 Linux 驱动和 RTOS，大三打电子设计竞赛拿了国二，找工作一路绿灯。建议学弟学妹早定方向、一个点打穿。

某
某双非本科 → FAE 现场应用工程师 2021 届 · 知乎 @2024

学校教的东西偏理论，示波器都没熟练就毕业了。第一份工作做 FAE 天天出差去客户产线调试，薪资一开始 8k 真心不高，跟同学做纯软比差一截。但三年后经验涨上来了现在 18k，胜在稳定且越老越吃香。硬件这行就是起步慢但天花板不低。

9
985 硕 → 腾讯后端开发（转行） 2018 届 · 校友访谈 @北京

大四拿了两个 offer：一个是某研究所电子岗 12 万/年，一个是腾讯后端 28 万/年。选了互联网，现在做了 4 年后端。实话实说电信的数理基础对学算法和系统设计很有帮助，但转行要补太多计算机基础课（计网/OS/数据库），相当于多花一年跟 CS 科班赛跑。不后悔，但确实比科班累。
