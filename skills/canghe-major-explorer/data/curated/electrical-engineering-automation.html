速览

电气工程及其自动化 = 强电(电力系统) + 弱电(电子控制) + 计算机技术的交叉学科, 是「不上网就是网」的硬核工科。国家电网每年招聘数万, 但基层运维与高端研发冰火两重天。适合数学物理扎实、动手能力强、能接受基层历练的人。

这个专业学什么?

前两年打数理和电路基础: 高等数学 / 线性代数 / 概率统计 / 大学物理 / 电路分析 / 模拟电子技术 / 数字电子技术 / 程序设计(C/单片机)。这些课挂科率普遍不低, 电路分析和模电尤其劝退。大三进入电气核心: 电机学 / 电力电子技术 / 自动控制原理 / 电力系统分析 / 电气控制及PLC / 电力拖动控制系统 / 高电压技术 / 继电保护原理。强电弱电两条线交汇: 既要懂电力系统短路计算, 也要会写单片机程序。大四: 生产实习(供电局/电厂/设备厂) + 毕业设计(电力系统仿真/智能电网/DSP应用)。

什么人适合?

数学物理能 hold 住, 尤其电路和电磁场不能晕。动手能力强 — 电机实验、PLC 接线、电路板焊接都需要实际动手。能接受基层岗位 — 电网市局/县局一两年基层轮岗是常态, 变电运维需要户外作业。如果只想在写字楼当白领、怕脏怕累慎入 — 电气工程的现场属性比计算机强得多。适合对「稳定」有刚需的家庭: 国家电网是性价比最高的体制内选择之一。

避坑指南

❌ 「电气 = 稳定高薪」 → 稳定是真的, 但高薪只限电网发达地区省/市局 + 注册电气工程师。县局第一年可能只有 5-8 万。❌ 「电气毕业只能爬电线杆」 → 偏见。电网(调度/继保/营销)、设计院、设备厂、新能源车企都大量招电气生, 并非都是户外作业。❌ 「强电比弱电高级」 → 没有高低之分。强电方向进电网容易, 弱电方向就业面更广(自动化/机器人/新能源)。❌ 「电气不用学编程」 → 大错。PLC 编程/单片机/C 语言/Python 仿真都是必修, 智能电网更看重计算机能力。❌ 「进电网 = 一劳永逸」 → 电网近年改革, 考核越来越严, 一线加班常态化, 而且晋升通道窄, 很多人 30 岁就遇到瓶颈。❌ 「名校电气 = 稳进电网市局」 → 电网校招看学校层次 + 专业对口 + 个人实力, 省局基本只要硕士, 本科生大部分从县局做起。❌ 「电气考研不如直接工作」 → 如果想进电网市局/省局或者设计院, 硕士学历几乎是硬门槛; 但如果只求县局或设备企业, 本科足够。

主要课程

全国 4 年制通用框架。电气是「宽口径」专业, 大三分流方向差异大: 强电方向(电力系统/继保/高电压)主攻电网就业, 弱电方向(电力电子/控制/嵌入式)就业面更广。课程整体偏难, 电路分析、电机学、自动控制原理是「三大挂科山」, 需投入大量时间做题和实验。

08 / 10 · 学长学姐说

学长学姐说

真实在校生/毕业生观点, 有夸有劝退, 自己判断。

某
某地级市电网 变电运维 2020 届 · 知乎 @2025

电气毕业进电网是主流选择, 但基层真的挺辛苦的。夏天变电站 40 度穿防护服巡检, 冬天户外抢修冻得手僵。工资在当地算中上, 但晋升很慢, 干了 3 年还是同岗。如果你对「稳定」有执念, 电网是好去处; 但如果你有冲劲想挣大钱, 趁早转码或去新能源企业。

汇
汇川技术 自动化工程师 2019 届 · 校友访谈 @深圳

没去电网, 去了工控企业。前两年出差特别多, 一年 200 天在客户现场, 但也确实学到东西 — PLC、变频器、伺服电机每天实战。第三年转研发, 薪资翻倍。电气这行经验很重要, 前 3 年别太在意工资, 多学技术、多积累项目经验, 后面有的是机会跳槽加薪。

华
华北电力大学硕士 → 浙江省电网 2021 届 · 知乎 @2025

本科双非, 考研到华电后确实改变了很多。电网校招时华电就是金字招牌, 甚至比部分 985 还好使。不过读研那两年真的很苦, 电气考研竞争一年比一年激烈, 分数线年年涨。如果本科院校一般又想进好电网, 考研是最值得的投资。

前
前电源工程师 → 转行新能源汽车 2018 届 · 校友访谈 @上海

做了 4 年电源研发, 从月薪 6k 到 18k, 但传统电源行业天花板明显, 果断跳去新能源车企。现在做电驱系统, 接触三电技术, 赛道热、薪资涨得快。电气是万金油专业, 找工作不愁, 但行业选择比努力重要 — 选对风口, 薪资翻倍不是梦。
