速览

编程是载体, 数学是底层。CS ≠ 写代码, 是用计算思维建模现实问题。4 年后能继续学新东西, 才是真功夫。

这个专业学什么?

前两年打数学 + 编程基础 (高等数学、数据结构、C/Python), 后两年分流到 AI / 系统 / 安全 / 图形学 等方向。算法竞赛 / 开源项目 / 实习 是 3 个最有用的课外修炼。

什么人适合?

数学不讨厌 (不一定要满分, 但不能高三看到概率就想跳), 喜欢拆解问题, 能耐住 4-8 小时 debug 的枯燥, 对'为什么这样设计'比'怎么用'更感兴趣。

避坑指南

❌ 数学不好硬学 → 大二会崩。❌ 只学课堂内容 → 校招简历空白。❌ 跟风报 AI 方向 → 实际可能做数据标注。❌ '35 岁危机'是真是假看赛道, 不看年龄。
