速览

数据科学 ≠ 学 Python 画图。是数学统计 + 计算机 + 领域业务的三栖学科。Gartner 测算 2025 年全球大数据人才缺口 1500 万, 互联网/金融/电信/医疗全线缺人, 应届月薪中位数 14-18k, 但淘汰率高 — 数学底子弱的慎入。

这个专业学什么?

前 2 年打地基: 高等数学 (微积分 + 多元) / 线性代数 (矩阵 + 特征值) / 概率论与数理统计 (假设检验 + 回归) / 程序设计 (C+Python+R) / 数据结构 / 数据库原理 / 离散数学。大三分流: 大数据存储 (Hadoop HDFS / HBase / Hive) / 大数据计算 (MapReduce / Spark / Flink) / 机器学习 (监督/无监督/深度学习入门) / 数据挖掘 (关联规则 / 聚类 / 异常检测) / 数据可视化 (Tableau / ECharts / D3.js) / 数据仓库 (数仓建模 / ETL / Kimball) / 分布式系统 / 自然语言处理入门。大四: 实习 + Kaggle / 天池竞赛 + 毕业设计 (Kaggle 赛题或企业真实数据)。一句话: 数学和代码两头都要硬, 哪头瘸了都走不远。

什么人适合?

数学不排斥 (高数挂科建议别来) + 能写代码 (不是只看教程) + 喜欢从数据里挖故事 (「为什么这个指标突然掉了 20%?」) + 能接受持续学习 (PyTorch 还没学透 TF 就过时了, Spark 上岗前还要补 Flink)。商科/文科生来可以, 但要补数学课; 纯理科 (物理/数学) 转行来也常见 — 反而比纯 CS 多一份统计直觉。

避坑指南

❌ 「学 Python 就能干数据科学」 → 大错。只会 sklearn 三行调包的人叫「调包侠」, 面试必问「为什么 XGBoost 比随机森林好?」「L1 L2 正则化本质区别?」。❌ 数学不扎实会撞天花板 — 高级岗 (算法科学家 / 量化研究 / 风控建模) 全是公式推导, 工程师做数据预处理 / ETL 5 年薪资涨幅 < 30%。❌ 「数据科学家」是 2018 年的叫法, 现在 JD 多是「数据分析师」「算法工程师」「数仓工程师」「商业分析师」, 选方向比选专业重要。❌ 数据岗 ≠ 高薪稳定: 2024 年大厂数据中台裁员 30%+, 取数 ETL 这种「SQL boy」可替代性极高, 要往算法/架构/业务理解上卷。❌ 统计学 vs 机器学习侧重不同: 强因果推断走 AB 测试 / 因果推断 (经济学/医学背景吃香); 强预测走深度学习 / 大模型微调 (CS 背景吃香)。别都学, 选一个钻。❌ 项目经验 > 学历: 简历上 1 个完整 Kaggle top 10% 比「985 数据科学硕士」更让面试官眼前一亮 — 课程项目 (豆瓣电影分析) 烂大街了。

主要课程

全国 4 年制通用框架。数据科学是「数学 + CS + 业务」三栖学科, 前 2 年和 CS 几乎一样 (高数线代概率 + C/Python), 大三开始分流: 大数据工程 / 算法 / 商业分析 三大方向。实习从大三暑假开始, Kaggle/天池/和鲸竞赛贯穿大三大四 — 简历上没竞赛没实习的求职者 HR 直接略过。

08 / 10 · 学长学姐说

学长学姐说

真实在校生/毕业生观点, 有夸有劝退, 自己判断。

字
字节跳动 算法工程师 (抖音推荐) 2019 届 · 校友访谈 @北京

数据科学最大优势是「数学 + 工程」两手都能干, 这在 AI 时代是稀缺品。本科毕业直接进大厂做算法 35k×16, 身边 70% 同学都这样。但 5 年后分化严重: 继续做工程的 30-50k 涨幅小, 走算法专家/管理路线 80k-150k。核心建议: 大三必须定方向, 什么都学最后什么都不精。

某
某 985 数据科学硕士 → 招商银行 风控建模 2020 届 · 知乎 @2025

数据科学真的万金油, 银行/券商/保险/互金都在抢。但和互联网不一样 — 金融要的是「因果推断」, 不是「预测准」。AB 测试、因果图、Uplift 模型这些互联网不教的东西, 进了银行才发现自己 1/3 知识要重学。商科 + 数学双背景的人反而在金融数据岗最吃香。

前
前阿里数据中台 → 创业做 AI 教育 2018 届 · 知乎 @2024

做了 5 年数据中台, 从 P5 到 P7。最终选择离开不是钱 — 是 2023 年发现「取数 ETL」这种工作正在被大模型和低代码平台替代, 留下来意味着和 22 岁毕业生竞争 SQL 谁写得快。数据中台裁员 30% 不是新闻, 还在这行的人都在往算法/AI 应用/数据治理转。

美
美团 商业分析师 (到店业务) 2021 届 · 校友访谈 @北京

没有走纯技术路线, 大三就意识到自己更爱看数据「讲故事」而不是跑模型。商业分析师天花板低 (总监级 60-100k), 但工作幸福度高, 不用 996 调参。文科 + 数据科学的复合背景在业务团队里反而吃香 — 老板需要的是「能听懂业务 + 能解读数据」的人, 不是只会跑 XGBoost 的工具人。
