速览

历史学不是「背故事」, 而是用史料 + 考据 + 理论解释过去如何塑造现在。本科就业面窄且起薪偏低, 教师 / 公务员 / 博物馆 / 文博单位是主要去处; 考研是改变命运的现实门槛 — 文史哲不分家, 越往上走越宽。

这个专业学什么?

前 2 年打地基: 中国通史 (古代/近代/现代) + 世界通史 (古代/近代/现代) + 史学概论 + 中国历史文选 + 古代汉语 (或文字学) + 史学论文写作。核心不是「记住哪年发生了什么事」, 而是学会「从一片碎陶片和一段残简里, 推断出一个朝代的经济结构和民族关系」 — 这是史料学 / 历史文献学 / 考古学概论给的能力。 大三大四分流, 大多数院校分 4 个方向: (1) 中国古代史 — 重点是先秦 / 秦汉 / 魏晋南北朝 / 隋唐 / 宋史的断代史; (2) 中国近现代史 — 鸦片战争到改革开放; (3) 世界史 — 各国国别史 + 区域史 + 国际关系史; (4) 史学理论 / 史学史 — 兰克学派、年鉴学派、后殖民史学、全球史等。本科阶段真正拉开差距的是: 古文阅读量 (繁体竖排无标点) + 一门外语 (世界史方向至少二外) + 一项史料工具 (甲骨文 / 金文 / 简牍 / 敦煌文书 / 历史地理 GIS)。 技能树三条: (1) 史料批判与考据 — 区分「史实」和「后人建构的叙事」, 学会看《史记》《资治通鉴》不同版本间的差异; (2) 文献检索与学术写作 — 一年读 30-50 本专著是常态, 论文写作是硬功夫; (3) 古文与外语 — 古文是古代史的门票, 外语是国际史学对话的门票。本科四年最大的隐性收获其实是: 训练了一种「长时段 + 多维度」看问题的方式 — 这在考公申论、面试讲故事、做研究时都极其受用。

什么人适合?

适合真正喜欢读书 + 坐得住 + 对「过去如何变成今天」有持续好奇的人。历史学是「长线专业」, 它的红利要 8-10 年后才兑现 (博士毕业进高校 / 研究院 / 文博单位)。如果你期待本科毕业就高薪, 会非常失望 — 2025 届历史学本科半年后月收入中位数约 4800 元, 在所有文科专业里处于偏低位置。 不适合: 把历史等同于「听故事」的人(史学是分析+批判+考据, 不是通俗演义); 排斥古文与繁体竖排的人(古代史方向必读《资治通鉴》《四库全书》影印本); 数学严重偏科但又拒绝接受统计训练的人(史学方法论在引入量化, 数字人文是前沿); 想本科毕业直接「挣大钱」的人(对口就业面窄, 起薪低, 改行率高)。适合的人是: 愿意用 5-10 年换一份「用历史眼光理解世界」的能力, 而且家里不指望他/她本科立刻反哺。

避坑指南

❌ 「学历史就是背朝代表」→ 这是高中错觉。史学核心是「为什么这么记载 / 谁记载的 / 怎么考辨真伪」, 不是「公元前 221 年秦统一六国」。只会背书的人, 会在大二史学概论和史料学直接熄火。❌ 「历史学冷门好考研」→ 半对半错。本科冷门是真的 (全国招生院校 200+, 但 985 录取线不低), 但考研「卷」的程度被严重低估 — 2024 年中国史考研报录比约 8:1, 顶尖院系 (北大 / 复旦 / 南大 / 人大) 报录比 30:1 起步, 跨考生挤爆。❌ 「不挑学校, 历史学都一样」→ 大错特错。北大的中国史、复旦的史学理论、南大的中国近现代史、人大的清史、北师大的史学方法、华东师大的史学史, 各有专精 — 学科壁垒比想象中厚得多。❌ 「本科毕业去当老师很轻松」→ 中小学历史教师岗位已严重饱和, 编制岗竞争比 30-50:1 (深圳南山区 2023 年一个初中历史岗 200+ 硕博竞争)。非师范类本科生想进公办学校基本要考研。❌ 「读历史学找不到工作」→ 也不完全对。公考 / 文博 / 出版 / 文化机构 / 媒体撰稿 / 高校行政 / 党政研究室, 都是出口。问题是对口起薪低 (5-8 万/年), 改行率高 (约 40-50% 毕业生最终不进史学相关行业)。❌ 「冷门好保研」→ 文史哲保研率相近, 历史学保研率约 10-15% (985), 比理工科低很多, 热门方向 (中国近现代史 / 史学理论) 推免竞争激烈。

主要课程

全国 4 年制通用框架。前 2 年通史打底, 大三分方向选断代史 / 国别史 / 史学理论。古代汉语是古代史方向的最大门槛 — 不会读繁体竖排无标点的文言文, 直接与先秦史绝缘。数学要求低, 但史学方法论和数字人文方向开始引入统计和 GIS。

学长学姐说

真实在校生/毕业生观点, 有夸有劝退, 自己判断。

北
北京师范大学 中国近现代史硕士 2024 届 · 知乎 @2025

本科南开, 大二就决定考研了 — 不考基本只能去县中当代课老师。史学的本科训练其实很好, 史料阅读、论文写作、长时段分析, 考公申论和面试讲故事都用得上。但我也承认, 同班同学有 6 个跨考了法硕和新传, 留下来继续读史的不到三分之一。真心喜欢就坚持, 不喜欢就趁早转 — 拖到大四很尴尬。

深
深圳某重点中学 历史教师 (编内) 2017 届 · 校友访谈 @深圳

深圳中学历史老师, 加上公积金年入 28 万左右, 寒暑假是真心爽。但要拿到这个岗, 我考了 3 年 — 第一年没进面试, 第二年笔试过了面试被刷, 第三年才上岸。同期竞争的全是北师大、华东师大的硕士。历史教师岗的饱和程度被严重低估了, 千万不要以为考个教资就能当老师, 编制岗基本要硕士 + 师范类 6 所出身。

国
国家博物馆 讲解员 2019 届 · 知乎 @2025

国博讲解员, 事业编, 北京户口, 一年 12 万左右。比钱更重要的是: 每天和文物打交道, 展品后面几千年的故事由你讲给公众听。但缺点也很明显 — 编制内晋升慢, 五年内基本工资不会有大变化, 同事很多都是北大考古文博学院的硕博。史学的本科直接进这种单位的概率几乎为零, 必须读研。

中
中央党校 党史教研部博士 / 高校讲师 2015 届 · 校友访谈 @西安

从历史学到党校, 走了 10 年。本科复旦 → 硕博连读 → 党校师资博士后 → 西部 985 讲师。年薪 18 万, 安家费 30 万。历史学的训练是「长线投资」, 你的同学在互联网挣到第一桶金时, 你还在写博士论文。但 35 岁之后, 高校教师 / 研究员的稳定性是其他行业给不了的 — 没有 35 岁焦虑, 没有中年失业, 越老越值钱。前提是 — 你能熬过前面 10 年的低收入。

某
某商业银行 客户经理 (改行) 2020 届 · 知乎 @2026

本科人大历史系, 毕业没考研, 进了银行做客户经理。第一年月薪 6000, 现在年入 22 万左右, 比同期考研的同学前 3 年挣得多。但精神上是撕裂的 — 4 年史学训练不是为了卖理财产品的, 每天看存款指标、应酬客户, 总觉得不是自己想要的生活。史学转行的优势是「能说会写」, 公务员、银行、媒体都认; 缺点是专业壁垒在转行那一刻就消失了, 5 年后没人记得你学过什么。
