速览

电子信息工程 ≠「学修电视」的老专业。是「软硬通吃」的万金油——既学电路板焊芯片，也写代码跑算法；通信、雷达、嵌入式、图像处理、芯片设计几乎都能切入。但「万金油」是双刃剑：样样都学，样样都不够深，方向选错就成打杂。

这个专业学什么?

前 2 年数学物理打底 + 编程入门: 高等数学 / 线性代数 / 概率统计 / 大学物理 (电磁学偏多) / 电路分析基础 / 模拟电子技术 / 数字电子技术 / C 语言 / 数据结构。这两年是分水岭, 物理数学不行的越往后越痛苦。 大三开始专业核心分流: 信号与系统 / 数字信号处理 (DSP) / 高频电子线路 / 通信原理 (调制解调/编码) / 电磁场与电磁波 / 微机原理与单片机 / 嵌入式系统 (ARM/Linux 驱动) / FPGA 设计 / MATLAB 与系统仿真 / 传感器与检测技术。课程密度大, 实验课多 (焊板子、调示波器、烧程序), 需要「坐得住 + 动手强」。 大四方向分流: 通信方向 (5G/卫星通信)、嵌入式方向 (智能硬件/IoT)、信号处理方向 (图像/语音/雷达)、芯片方向 (数字 IC/模拟 IC/FPGA)、光电方向。每个学校强势方向不一样, 选校比选专业更重要。

什么人适合?

物理数学不能差 (电路、电磁场、信号与系统全是数学), 动手能力要强 (实验室是常态), 编程要愿意啃 (C 语言 + 嵌入式 + MATLAB 跑不掉), 不排斥硬件 (要焊板子、看 datasheet、调示波器)。这个专业最怕「软硬都不想学只想搞钱」的人——EE 方向窄, 但「宽口径」必须建立在「至少一头钻得深」上。 不适合纯软件思维或纯硬件思维的人——纯软件去计科, 纯硬件去微电子/材料。如果高中物理电学部分就头疼, 高数也学不动, 慎选。

避坑指南

❌ 「电子信息 = 学修手机/家电」 → 严重误读。现代 EE 是「芯片 + 通信 + 信号处理」三角, 和「修电视」隔了 30 年。❌ 「EE 什么都学 = 什么都好找工作」 → 错。「万金油」= 啥都学一点, 面试一问就露馅。企业招人要「专才」, 本科不深挖一个方向, 简历就埋没在池子里。❌ 「本科毕业能进华为海思做芯片」 → 海思/中兴/展锐的 IC 设计岗 985 硕士起步, 本科只能做测试/验证/FAE。❌ 「不读研也能拿高薪」 → 通信和 IC 方向 70% 的核心岗位卡硕士, 嵌入式/嵌入式软件本科勉强能进, 但起薪低 30%。❌ 「学了 EE 转码农很容易」 → 部分对, 但 EE 转码的黄金窗口在缩小——直接学 CS 的人编程能力往往更强。❌ 「信号处理很玄学, 工作用不上」 → 5G/雷达/语音识别/医疗影像全靠信号处理, 只是本科课本和工业差距大, 要自学。❌ 「模电数电是核心」 → 经典知识, 但 2025 年后数字 IC 设计主流是 Verilog/SystemVerilog + EDA 工具, 手工分析电路图的时代过了。

08 / 10 · 学长学姐说

学长学姐说

真实在校生/毕业生观点, 有夸有劝退, 自己判断。

华
华为海思 · 数字 IC 设计工程师 2018 届 · 知乎 @2024

EE 是「万金油」但万金油不等于好找工作。本科毕业去了某 ODM 厂做硬件测试, 月薪 8k。读了西电通信硕后, 跳槽海思做数字 IC, 年薪直接翻 3 倍。这行卡学历是真的——面试海思时一组 12 人, 11 个硕士, 我是少数本科能进的。

大
大疆创新 · 嵌入式算法工程师 2020 届 · 校友访谈 @深圳

电子信息最大的好处是「路宽」——通信、嵌入式、信号处理、IC 都能转。我大三自学了 STM32 + RTOS + 一些 CV 算法, 秋招拿了 5 个 offer。最后选大疆是因为喜欢无人机。EE 学的电磁场、高频课工作几乎用不上, 但数学基础 + 硬件思维让我学任何方向都快。

前
前中兴 → 转行 Java 后端开发 2019 届 · 知乎 @2025

通信原理学了 4 年, 工作 3 年发现: 通信行业的「黄金期」过了。5G 建设放缓, 运营商集采价格年年降, 加班强度大但薪资增长慢。30 岁前果断转码, 同学里 40% 都走了类似的「EE 转 CS」路线。不是说 EE 不好, 是 CS 的就业面和薪资上限更高。

比
比亚迪 · 车载嵌入式软件工程师 2021 届 · 校友访谈 @深圳

选 EE 不后悔。新能源车风口来了, 车载嵌入式 (ECU/ADAS/座舱) 全是 EE 的人在做。本科同学里去了华为/中兴/比亚迪的, 起薪比 5 年前高了 50%。但课程确实陈旧——4G/5G 教得浅, FPGA 实验还在用 7 系, 真正找工作靠自学。建议选 EE 的同学大二就定方向, 别等大四。
