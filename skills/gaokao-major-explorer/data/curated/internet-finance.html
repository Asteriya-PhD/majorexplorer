速览

互联网金融的本质是「金融学底层逻辑 + 互联网产品方法论 + 数据/合规/监管」三栖训练, 它既不是计算机学位 (无法走纯算法岗), 也不是传统金融学 (互联网产品+数据课远超金融学), 在 2021+ 蚂蚁/京东金融等强监管整改后, 「合规收紧 + 业务收缩 + 同质化竞争」是该专业三大隐藏风险.

01这个专业学什么?

大一通识: 微观经济学 / 宏观经济学 / 货币银行学 / 会计学基础 / 高等数学 / 线性代数 / 概率统计; 大二核心: 互联网金融概论 / 金融工程 / 计量经济学 / 区块链与加密货币 / 数据库与 SQL / 互联网产品经理基础; 大三方向分流: 互联网金融产品 / 风控建模与数据分析 / 金融科技监管与合规 / 数字支付与运营 / 互联网理财与资管 五选一; 大四毕业实习 (互联网大厂金融业务/银行金融科技部/消金/支付公司) + 毕业论文. 4 年下来, 既能看懂资产负债表/金融衍生品定价, 也能画原型图/跑 SQL/读监管文件.

02什么人适合?

✓ 适合
  • 对金融学底层逻辑 + 互联网产品/数据/合规有复合兴趣, 不排斥编程基础 (Python/SQL)
  • 愿意主动补互联网产品方法论 (用户调研/产品画原型/A/B 测试), 不期望「做程序员」
  • 接受 5 年长跑 (本科 + 硕士 + CPA/CFA/FRM 证书 + 互联网/银行实习), 头部产品岗硕士起步
  • 愿意走体制内 (人行/银保监/金融稳定发展委) 或互联网大厂金融业务/银行金融科技部/消金牌照公司
✗ 不适合
  • 本意是想做 CS/软工程序员, 因分数不够转而「曲线救国」 — 该专业核心是金融而非代码, 真想写代码请选 CS
  • 想进传统银行核心岗 (信贷/投行) — 该专业产品+数据课远多于传统金融课, 校招传统银行路径不占优
  • 期待「互联网大厂 40 万+ 应届 offer」— 头部互联网金融产品岗普遍要求 985 硕 + 大厂实习, 普通本科多走运营/客服
  • 把互联网金融等同于「P2P/网贷/虚拟币」 — 该专业毕业后核心是持牌机构合规岗, 不碰高风险业务

03避坑指南

  • 互联网金融 = 计算机 + 金融双学位
    绝大多数院校授予「经济学学士」(代码 0203T 特设), 计算机/编程课程是「数据库/Python/RPA」基础, 不构成第二学位; 想拿计算机学位必须考软件工程, 不能通过互联网金融「曲线救国」当程序员.
  • 互联网金融岗位需求很大, 应届直接进蚂蚁/京东数科
    2021+ 蚂蚁集团整改、京东数科收缩、监管收紧背景下, 互联网金融行业校招规模较 2018-2020 缩水 40%+; 头部大厂 (蚂蚁/腾讯金融/京东数科/字节金融) 应届招录集中 985 硕, 普通本科多走中小消金牌照公司运营/客服岗.
  • 懂金融 + 懂互联网 = 高薪产品经理
    互联网金融产品岗竞争来自三个方向: 纯 CS 转产品的 (懂技术) / 传统金融硕士转产品的 (懂金融) / 海归金融硕士 (懂双语 + 行业) — 单一「互联网金融」本科背景需要靠「985 校 + 大厂实习 + 真实项目」才能突破, 不是「专业对口」就能拿 offer.
  • CFA/FRM 证书是必拿
    CFA 在国内互联网金融领域认可度远低于传统资管, FRM 在风控/合规岗有加成但不是硬门槛; 头部互联网大厂更看重「实习项目 + SQL/Python 实战 + 产品/数据作品集」, 证书是锦上添花而非雪中送炭.
  • 区块链/加密货币是核心方向
    国内 2017+ 全面清退 ICO, 2021+ 严控虚拟货币交易, 高校「区块链与加密货币」课程多为科普级, 实际毕业生进入正规持牌机构 (银行/券商/消金牌照公司) 几乎不涉及加密资产; 真想做加密/Web3 要去新加坡/迪拜, 国内合规框架不支撑.
  • 互联网金融 = 低门槛, 什么人都能学
    该专业实际课业密度大: 金融学 (宏微观 + 计量 + 金融工程) + 计算机基础 (Python/SQL/数据库) + 互联网产品方法论, 三线并行; 数学/编程薄弱者会在大二下 - 大三明显掉队, 不是「金融 + 互联网」简单加法.

学长学姐说

真实在校生/毕业生观点, 有夸有劝退, 自己判断。

招
招商银行金融科技部 · 产品经理 2022 届 · 中央财经大学 2022 届 @ 深圳

本科阶段金融学 + 互联网产品 + SQL/Python 的复合训练, 让我在招行 FinTech 校招里脱颖而出. 但工作后发现「互联网金融」光环在 2021+ 整改后褪色, 真正能进头部大厂的还是 985 硕 + 大厂实习, 单一本科突围很难.

蚂
蚂蚁集团 · 风控策略分析师 2021 届 · 对外经济贸易大学 2021 届 @ 杭州

毕业后在蚂蚁做风控策略 3 年, 互联网金融的核心是「合规 + 业务 + 数据」三者平衡, 任何一个偏科都会卡住. 我们那一届真去头部大厂的不多, 不少同学去了银行 FinTech 部/消金牌照公司, 头部岗位竞争远比想象中激烈.

马
马上消费金融 · 风控建模岗 2020 届 · 西南财经大学 2020 届 @ 重庆

选择马上消金是因为持牌 + 风控场景真实, 三年下来模型 + 业务双线成长. 但要说一句实话: 互联网金融本科直接拿头部大厂 offer 的不到 20%, 大部分去的是持牌消金/银行 FinTech, 想冲头部必须读研.
