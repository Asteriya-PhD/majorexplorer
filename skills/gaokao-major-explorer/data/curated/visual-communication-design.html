01 / 10 · OVERVIEW

速览

视觉传达设计是「让信息更美更有效」 — 品牌设计 + 字体设计 + 包装设计 + 海报设计 + 书籍设计 + UI/UX + 数字媒体设计 + 影视动画包装, 是「平面 + 数字 + 商业」交叉。本科起薪 7-12 万, 头部互联网 (字节/腾讯/阿里/小米) UX 岗校招 18-30 万, 4A 广告/品牌咨询/出版/独立设计师, 是「艺术 + 商业 + 互联网」复合性价比之王。

这个专业学什么?

前 2 年基础: 美术基础 (素描/色彩/速写) + 设计基础 (构成/色彩/透视) + 设计史 (现代设计史/中国设计史) + 字体设计基础 + 摄影基础 + 软件基础 (PS/AI/ID/Sketch/Figma) + 图形语言 + 设计思维 — 美术功底 + 设计思维 + 软件工具的三脚架。 大三大四分流到 5 大方向: (1) 品牌设计 (Logo / VI / 品牌策略 / 品牌咨询, 跟 4A 广告 + 品牌咨询公司强相关); (2) 包装设计 (食品/化妆品/电子产品/快消品包装, 跟消费品行业强相关); (3) 编辑设计 (书籍/杂志/画册/海报/视觉出版物, 跟出版社/工作室强相关); (4) UI/UX 设计 (App/网页/小程序/车载/HMI 交互设计, 跟互联网/智能硬件强相关); (5) 数字媒体设计 (动态海报/影视包装/信息可视化/动态图形 MG, 跟影视/广告/互联网强相关)。 技能树四条: (1) 平面软件精通 (PS/AI/ID/C4D/AE/Figma/Sketch 至少 4 个); (2) 字体设计与排版 (中英文字体设计 + 网格系统 + 书籍装帧); (3) 品牌策略与设计系统 (Design System / 品牌识别系统 / 用户体验地图); (4) AI 设计工具 (Midjourney/Stable Diffusion/Runway/Sora 是新基础设施, 2024 年起 985 视传学生必会)。视传的核心是「用视觉语言解决商业 + 文化 + 用户体验问题」, 是「离商业最近的纯艺 + 设计交叉」专业。

什么人适合?

适合对「让一个 Logo 改变品牌」「让一个 App 改变用户行为」「让一本杂志变成收藏品」有持续热情, 且能接受前期熬夜做稿 + 中期对接客户 + 后期持续学习新软件的人。视传的优势是「艺术 + 商业 + 互联网」三栖: 它的就业不像纯艺那样「毕业即失业」, 也不像纯工科那样「35 岁焦虑」, 而是「视觉能力 + 设计思维」的复合背景, 5 年后能到 30-60 万, 头部能到 50-100 万。 不适合: 把视传等同于「学画画」的人 (这是「设计 + 商业」, 主体是「用设计解决问题」); 不能接受熬夜做稿的人 (4A 广告/互联网「9105/9106」是常态); 数学/物理极差但想进互联网交互岗的人 (UI/UX 涉及数据思维 + A/B 测试 + 用户研究); 期待「对口考公岗位多」的人 (视传公务员岗位少, 主要靠企业/工作室/自由职业)。适合的人是: 喜欢「美学 + 商业 + 用户体验」交叉, 愿意前 5 年在广告/互联网/品牌/工作室做设计师, 之后做设计总监/创意总监/独立设计师/创业的人。

避坑指南

❌ 「视传就是平面设计, 工资低」→ 严重低估。视传校招 7-12 万, 互联网 UX 校招 18-30 万, 4A 广告 12-20 万, 5 年后资深设计师/创意总监能到 30-80 万。视传是「艺术类里起薪高 + 商业化最好」的专业之一。❌ 「视传毕业 = 画图机器」→ 错。视传的核心是「设计思维 + 品牌策略 + 用户研究」, 头部 5% 设计师做的是「设计总监 + 品牌策略 + 用户体验」, 不是「美工」。AI 时代 (2024 起), 只会画图的美工正在被淘汰, 「懂策略 + 懂用户 + 懂商业」的全能设计师反而更值钱。❌ 「视传进大厂容易, 应届 30 万+」→ 部分对。央美国美江南大学/同济/清美/浙大等头部 5 院校, 校招进字节/腾讯/阿里/小米 UX 岗 18-30 万, 是真实的; 但普通院校视传校招进互联网 UX 难度大, 起薪 7-10 万。❌ 「视传和动画/数字媒体一个专业」→ 严重错。视传 (偏品牌 + 包装 + 编辑 + UX/UI, 平面 + 数字) 跟动画 (偏二维/三维/定格动画, 影视/游戏) 和数字媒体艺术 (偏影视/游戏/交互/装置, 数字 + 科技) 是不同方向, 选错后悔 4 年。❌ 「4A 广告黄金期已过, 没前途」→ 部分对。2018-2022 4A 广告巅峰期, 奥美/李奥贝纳/麦肯/智威汤逊校招 12-20 万; 2023 年起 4A 缩招, 大量视传转互联网 UX/品牌/独立设计师。但「品牌设计 + 品牌咨询」依然有生命力, 4A 仍能到 12-20 万。❌ 「AI 时代设计师要被淘汰」→ 过度焦虑。AI (Midjourney/Stable Diffusion) 是设计辅助工具, 2024 年起 985 视传学生必会; AI 不会取代「懂策略 + 懂用户 + 懂商业」的全能设计师, 反而会替代「只会画效果图」, 视传的复合门槛是护城河。❌ 「视传冷门好考, 容易上岸」→ 被严重高估。央美/国美/清美/江南大学 视传 2024 年河北物理组最低 590-630 分, 985 分数打底, 不是「保底」专业。

08 / 10 · VOICES

学长学姐说

真实在校生/毕业生观点, 有夸有劝退, 自己判断。

江
江南大学 视传硕士 2024 届 · 知乎 @2025

本科江大视传, 大二确定考研江大视传。说实话, 视传是「艺术类里商业化最好 + 起薪高」的专业之一。校招 UX 18-30 万, 4A 广告 12-20 万, 5 年后资深设计师/创意总监能到 30-80 万。AI 时代 (2024 起), 985 视传学生必会 Midjourney/Stable Diffusion/Runway, AI 是工具, 不会取代「懂策略 + 懂用户 + 懂商业」的全能设计师。真心喜欢美学 + 商业 + 互联网就来, 怕熬夜慎选。

字
字节跳动 UX 设计师 (北京) 2019 届 · 校友访谈 @北京

本科央美视传, 毕业进字节做 UX。第一年 32 万, 现在 5 年经验 70 万。字节 UX 中心是「996 + 高薪 + 成长快」组合, 适合愿意拼 + 愿意学的同学。视传不是「画图机器」, 字节 UX 中心招的是「设计思维 + 品牌策略 + 用户研究」的全能设计师, 985 起步 + 作品集 + 英文加分。真心推荐: 视传校招进互联网是「艺术类里起薪高 + 路径清晰」性价比之王。

奥
奥美广告 创意总监 (上海) 2016 届 · 校友访谈 @上海

本科国美视传, 毕业进奥美做设计师。第一年 15 万, 现在 8 年经验 50 万 + 创意总监岗位。4A 广告的「工作氛围相对最好」, 适合有审美追求 + 喜欢品牌 + 不怕熬夜的同学。但 2023 年起 4A 缩招, 建议校招两手准备 — 4A + 互联网 UX + 品牌咨询 + 独立设计师, 多条腿走路。视传不是「夕阳行业」, 是「复合背景 + 跨界能力」的新蓝海。

小
小米科技 UX 主管 (北京) 2018 届 · 校友访谈 @北京

本科同济视传, 毕业进小米做 UX 主管。第一年年薪 18 万, 现在 6 年经验 45 万。小米 UX 是「智能硬件 + IoT + 互联网」复合方向, 985 起 + 作品集 + 技术理解。视传想进互联网 UX, 必备: (1) 985/211 头部 5 院校; (2) 高质量作品集; (3) 至少 1-2 个真实项目; (4) AI 工具 + 数据思维。真心推荐: 视传不要死磕「4A 广告」, 互联网 UX 是新蓝海, 985 起点 5 年后能到 50 万。

正
正邦品牌 设计总监 (上海) 2020 届 · 知乎 @2025

本科江大视传, 毕业进正邦做品牌设计。第一年 12 万, 现在 4 年经验 28 万 + 设计总监岗位。品牌设计 + VI + 品牌咨询是正邦强项, 服务过伊利/农夫山泉/中信银行。视传不是「只能做美工」, 头部 5% 设计师做的是「品牌策略 + 创意总监 + 设计管理」, 985 起 + 3-5 年深耕, 5 年后能到 30-60 万。
