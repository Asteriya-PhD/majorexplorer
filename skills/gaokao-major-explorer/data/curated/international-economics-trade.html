速览

国贸不是「学外贸」那么简单 — 是经济学 + 国际商法 + 跨境实操三位一体的交叉学科。风口在跨境电商 + 涉外合规 + 区域国别研究, 传统外贸业务员岗位大幅萎缩。英语不是「加分项」是「生死线」, 哑巴英语基本告别高薪岗。

这个专业学什么?

前两年: 微观/宏观经济学 + 高数 + 线代 + 概率论 + 会计学原理 (经管类通用底盘), 同时死磕大学英语 + 商务英语听说读写。大二是分水岭, 英语好的人开始接触外教全英文专业课, 英语差的人会被老师善意劝退到「国际商务」或「市场营销」等出口。 大三: 国际贸易学 (克鲁格曼经典教材中文版) + 国际金融 + 国际商法 (Incoterms 2020/UCP600) + 外贸函电 + 国际结算 + 单证实务 + 国际市场营销 + 跨境电子商务 (实操平台: 速卖通/Shopee/Amazon 选品与运营)。这是核心技能树, 也是和「经济学」专业最本质的区别 — 后者偏理论, 国贸偏「在国际规则下做生意」。 大四: 按方向分流 — 传统外贸 (进出口流程 / 报关报检 / 信保) / 跨境电商 (平台运营 / 独立站 / 海外社媒) / 国际金融与投资 (外汇 / 国际结算 / 跨国公司财务) / 涉外合规与法律 (WTO / 反倾销) / 区域国别研究 (RCEP / 一带一路)。毕业论文常常做「中美贸易摩擦对 X 行业影响」「中国新能源汽车出口的关税博弈」这类强时效性选题。

什么人适合?

适合英语听说读写流利 + 对国际贸易实务有兴趣 + 不排斥频繁出差 (东南亚 / 中东 / 非洲广交会 + 客户拜访) + 接受初期薪资不高的考生。这个专业对「外向型性格 + 跨文化沟通」要求很高 — 你能不能在广交会上一晚上和 30 个非洲 / 中东客户寒暄、报价、递名片, 决定你 5 年后是销售经理还是普通跟单。 不适合以下几种: 哑巴英语 (四六级低分飘过, 听到英文电话就心跳加速) / 极度内向 / 排斥「按订单吃饭」「时差加班」「客户宗教忌口也要陪着吃」的人 / 想进体制内拿铁饭碗 (国贸考公岗位少, 三不限除外) / 期待「学了就能去联合国 / WTO」的人 (那是国关 / 国际法的赛道)。

避坑指南

❌ 「国贸 = 高薪外向型」 → 80% 毕业生月薪 6-10k, 真正高薪的跨境电商运营 / 涉外合规 / 投行国际部不到 15%。❌ 「英语好就能做国贸」 → 英语只是门票, 业务能力 (找客户 / 谈价格 / 处理索赔) 才是分水岭。❌ 「传统外贸还是铁饭碗」 → 2015 年后外贸业务员岗位萎缩 40%, 现在是跨境电商 + 独立站 + 短视频出海的时代。❌ 「毕业就进商务部 / WTO」 → 国考岗位极少, 外交部小语种优先, 国贸基本走三不限卷王局。❌ 「国贸万金油哪里都能去」 → 恰恰是哪里都不专。HR 招「国贸」岗少, 招「跨境电商运营」「海外销售」「外贸单证」多, 名字相近不是同一份工作。❌ 「广交会人脉 = 真功夫」 → 90% 广交会名片回家后没下文, 真功夫在校招 + 实习 + 跨境实操账号。❌ 忽视区域国别风险 → 2024 年红海危机让很多外贸订单取消, 选「俄罗斯 / 伊朗 / 中非」客户群尤其要评估政治风险。

主要课程

全国 4 年制通用框架, 总学分 150-170。学科最像「经济学 + 英语 + 法学」三合一。英语是隐性毕业门槛 — 多数名校要求专四或六级 550+; 对外经贸大学部分专业课全英文授课。跨境电商课在 2020 年后成为新增必修, 反映行业从「传统外贸」向「数字贸易」迁移。

08 / 10 · 学长学姐说

学长学姐说

真实在校生/毕业生观点, 有夸有劝退, 自己判断。

S
SHEIN 海外品牌运营 (广州) 2022 届 · 小红书 @2025

国贸毕业最正确的决定是大二就开始做速卖通个人店铺。毕业时月销 5 万美金的小店就是简历。从小白到运营组长花了 2 年, 现在带 8 个人团队, 年包 35 万。同期去传统外贸公司的同学月薪还在 8k 徘徊 — 这行已经不是「等客户上门」的时代了, 是「在 TikTok 投流 + 数据选品」的时代。

某
某 985 副教授 (国际商务硕) 2018 届 · 校友访谈 @南京

读完研进了高校, 发现国贸这门学科和 5 年前完全不一样了 — 现在老师上课不讲传统贸易理论, 直接上 GeoGuessr + 模拟沙盘 + 跨境电商实操。当时我们班 80% 去了外贸公司, 现在学生 50% 进了跨境电商和出海品牌。这是时代给的窗口期, 谁能跑得快谁赢。

中
中国进出口银行 客户经理 (北京) 2020 届 · 校友访谈 @北京

政策性银行的性价比被严重低估。年薪看着 18 万, 但户口 + 公积金 + 补充医疗 + 子女教育资源打包算下来, 比 30 万的私企香。而且 6 年后升副处, 整个职业路径越走越稳。进这家的秘诀只有一个: 国贸专业 + 大三拿到六级 580 + 两段银行实习。

中
中型外贸公司 业务员 (深圳) 2019 届 · 知乎 @2025

劝退贴。国贸 2015-2020 是黄金期, 现在是青铜期。我们公司今年裁了一半业务员, 留下来的底薪降到 4500, 主要靠订单提成。广交会去了 3 届, 90% 名片回家后没下文。如果你家里没外贸客户资源, 不要进这行 — 跨境电商至少自己干, 传统外贸是给老板打工。

字
字节跳动 TikTok Shop 海外运营 (新加坡) 2021 届 · 校友访谈 @新加坡

国贸最魔幻的是 — 我们专业 60% 同学毕业没做国贸。做外贸 5 个, 做跨境电商 8 个, 银行 4 个, 公务员 3 个, 还有 7 个读了研, 4 个直接转行做互联网产品和海外营销。国贸是「商科里的英语专业」, 真正的核心能力是英语 + 商业敏感度 + 抗压。这三项无论做外贸、跨境还是外企都通用。
