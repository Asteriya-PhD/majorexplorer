速览

什么人适合?

Fit Check
✓ 适合
  • 数学强 (高考数学 140+ 或数竞省二以上) 且喜欢数学
  • 编程 0 基础愿意大二前补齐 C++/Python
  • 想拿年薪 50 万+ Quant 岗 (名校 + 强实习前提)
  • 心理素质好, 能承受一天 -30% 回撤
  • 目标顶级私募 / 外资行 / 公募基金量化部
  • 愿意读名校 (清北复交 + 两财一贸 + 头部 985)
✗ 不适合
  • 数学一般 / 看到积分就头疼 (随机微分方程会劝退)
  • 编程 0 基础且不想补 (C++ 是 Quant 硬门槛)
  • 期待「稳定坐办公室」 (Quant 凌晨盯盘是常态)
  • 心理素质差 / 输不起 (一天回撤 30% 真的会哭)
  • 想稳定考公 (本专业考公只能三不限, 竞争比 300:1)
  • 双非 + 想进顶级私募 (基本无门, 学历卡死)
03 / 03

避坑指南

6 个常见误区
误区 01
❌ 金融工程 = 学金融的工程版
70% 课程是数学和编程, 金融只是应用层。本质是「数学专业的金融方向」, 不是「金融专业的数学加强版」。
误区 02
❌ 学完就能进高盛/摩根士丹利
顶级外资行国内校招基本只清北复交 + 海外 Top 30, 其他学校连 HR 简历关都过不了, 学历卡死。
误区 03
❌ C++ 学不会可以靠 Python
低延时交易 (HFT) 全部 C++, Python 只能做中低频策略, 高薪 Quant 岗 90% 要求 C++ 熟练。
误区 04
❌ 金融工程比金融学更好就业
头部年薪 80 万+, 尾部更惨 (双非金工 ≈ 转柜员/销售/客服), 窄门特征明显, 不像金融学有「万金油」退路。
误区 05
❌ 量化就是敲代码, 不需要社交
Quant 需跟 Trader/PM/Risk/IT 联调沟通, 沟通能力差只能做底层研究员, 升不到 PM / Partner。
误区 06
❌ 挂科率高是正常的, 熬过去就行
随机过程 / 数值方法挂科率超 30%, 很多人挂 2 门直接分流/转专业/退学, 「熬过去」的只有原本就强的人。

08 / 10 · 学长学姐说

学长学姐说

真实在校生/毕业生观点, 有夸有劝退, 自己判断。

幻
幻方量化 Quant Researcher 2024 届 · 校友访谈 @杭州

北大数院本科 → 幻方 Quant, 应届 base 75 万 + 一年奖金 50 万。每天 9 点写策略, 凌晨 1 点跑回测, 周末盯盘。C++ 是命根子, Python 是日常, 数学是天花板。同学里有 1/3 转 IT (去字节/阿里), 1/3 出国, 1/3 留 Quant。这行就是「智力 + 体力 + 抗压」三合一, 缺一个就退出。

中
中信证券 卖方分析师 2023 届 · 知乎 @2024

上财金融工程本科 → 中信研究部, base 35 万。第一年就是写报告 + 路演 + 模型维护, Excel 建模是基本功, Wind/Bloomberg 闭眼用。但卖方研究竞争白热化, 头部 30% 拿行业 70% 的奖金, 剩下的人 5 年内会被淘汰。校友圈里, 真正能留下来的不到一半。

招
招商银行 FinTech 管培生 2022 届 · 小红书 @2023

央财金融工程本科 → 招银网络 (招行金融科技子公司), base 28 万。班里 80 人, 32 个去了 Quant/卖方/PE, 25 个去了银行/券商中后台, 15 个读研, 8 个彻底转行 (IT/公务员/出国)。金融工程是真的「窄门」, 但银行/券商 IT 这条通道给了普通人一条活路——不用拼 C++, 会 Java/Python 也能进。

转
转码 → 字节跳动 后端开发 2021 届 · 一亩三分地 @2022

复旦金工本科, 实习全挂 (高盛/中金/中信暑期都没进), 秋招 Quant 也全军覆没。最后 4 个月死磕 Java + LeetCode, 转码去了字节后端, base 38 万。说实话, 金工 4 年数学没白学——算法题秒杀, 同事 CS 出身的反而没我数学直觉强。但「金工转码」这条路没人带, 全靠自己摸索, 很孤独。

证
证监会 公务员 (金工出身) 2019 届 · 校友访谈 @北京

上财金工本科, 毕业先去私募做策略研究员, 干了 2 年熬不动 (凌晨盯盘 + 30% 回撤 + 老板甩锅), 考公进了证监会, 年薪 25 万 + 北京户口 + 编制。收入是 Quant 同学 1/4, 但生活质量高 10 倍。金融工程考公只能报「三不限」或「经济学类」, 竞争比 300:1, 我是考了 3 次才上岸。
